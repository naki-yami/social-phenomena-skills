# 社会现象分析（方法论）

**把「感觉」变成可复现的读数，再把读数落回一张能被推翻的判断卡。**

对象不限于新闻：哲学、政治、经济、金融、历史、AI、佛学都真跑过。这套东西分三层——**方法论**（怎么想才不自欺）＋ **尺子**（四条通道的判据）＋ **账本**（每条判据都对着真实语料标定过，标定失败的也留在里面）。本 skill 只带前两层与纪律，**账本按路径引用**（见文末）。

## 默认入口 · 「分析 X」＝一条全流程

用户说**「分析 X」「分析一下 X」**时，**不用问要不要联网**，直接按下面走（细节见 `references/全流程_从题目到三份产物.md`）：

**要联网 → 先列「谁可能有话要说」→ 抓料 → 分流并重数 → 跑读数 → 分析 → 出三份产物。**

1. **要联网权限**：材料自己去拿。本机沙箱默认断网，**先按轮申请**；拿不到就明说拿不到，只出结构层并标「未验证」。
2. **先列名单再搜**：当事各方／第三方／反向材料／底本，四类各写一遍。抓完逐条回填**谁一份都没拿到**。
3. **抓料**：落 `{题名}_素材\`，每份带 `原发日期`（文书另加 `文书日期`——**网页发布日期 ≠ 文书原发日期**）；抓取日志与被排除的索引页落 `{题名}_素材_排除\`，**排除留痕，不静默删除**。
4. **跑读数**：`sitongdao` 的四通道，分开报，不合并总分。
5. **分析**：下面的次序（自指 → 类型 → 结构四问 → 双轴 → 六域 → 判断卡）。
6. **出产物（固定三件）**：
   - **① 报告文本** `{题名}分析_{日期}.md`——**全量**：逐份读数、全部数字、判据、推理、边界。开头先写「能说什么、不能说什么」。
   - **② 发表稿** `{题名}_发表稿_{文章标题}.md`——**文章体**，给普通读者：同一个结论，换成能直接发表的语言。
     **不带方法论术语**（`自指／四通道／双轴／六域路由／判断卡／置信度档位／失效模式编号／来源面偏置` 一律不出现在正文里），但**该有的一个不少**：结论 ＋ 把握程度（说人话）＋ 三条反证（写成「什么情况下这篇文章是错的」）＋ 取材缺口（单列一节，**「没抓到」与「没去试」分开写**）。数字必须与报告一致。
   - **③ 结构图** `{题名}_结构图_archify.html`——与报告并列的第三件：讲清「谁和谁连、哪块缺席、**这张结构推出什么**」。
     ```
     node "<archify>/bin/archify.mjs" finalize architecture <candidate.json> <out.html> --quality showcase --json
     ```
     四道闸全 `pass` 且 `ok:true` 才算过；用 `schema_version` 按类型选、**不手写 `meta.viewBox`**、`tag` 不渲染（并进 `sublabel`）。**只画关系不画结论＝读者收获不到信息，返工**：必须有**推论带**（`推论①→②→③→断言`，独立边界框标「由上面这张结构推出」）且**卡片第一张是结论卡**。细则见 `references/可视化规范.md` 第六节。
   - **不默认交付**：`{题名}_可视化看板.html` 与 `{题名}_分析路径_archify.html`（可作中间产物；做完移入 `outputs\_未采用\`，**留档不删**）。看板生成器仍在 `scripts/build_report_html.py`，八节骨架契约见 `references/可视化规范.md`。
   - **交付＝打开，不是给路径**：三件全部用 `open_in_codex` 打开（HTML 会以 **Web preview 卡片 · Open in** 出现在对话里）。对话里**只说结论、把握程度、还缺什么三句**，正文与图一律不贴——除非用户明确要求「贴出来」。

**分流之后必须重数（会改事实的一步）**：索引页／导航页被移出后，**任何按份数写的表（来源面、各分类计数、看板数据、结构图节点）都要用语料自己的 `分类` 字段重新汇总**，不能沿用抓取时的快照。分桶错而总数对 ⇒ **不触发任何自动检查，只能靠逐份重数抓出来**；发现不一致就改，并在正文以「订正」块留痕，**不静默改数**。

**产物的分工是硬规矩**：数字与明细**只住报告**；发表稿只带**正文里站得住的那几个数**；结构图**不放明细**。
**来源面偏置（只拿到一方）必须连着结论一起报**，图里缺席要用斜纹画出来。

## 用与不用

用：任何有结构、有视角、有代价的对象。
不用（四种，硬用就是自欺）：

1. 信息量不足以答结构四问——此时任何结论都是编的；
2. 时间窗短于一天——最慢的是代价流向那一步，急事要另设快通道；
3. 纯随机或纯自然事件（地震、抛硬币）——硬套结构就是万能钥匙谬误；
4. 纯个人情绪事件——那不是局势分析，是内省。

一条硬边界：**结构分析能解释，但不必然能预测。** 当市场由信念驱动时，叙事轴的权重必须压过结构轴。

## 次序（不可换）

**先定位观察者，再看客体，再谈证据，再出判断，最后落回自己。** 换了，后面全是错位的。

### 第 0 步 · 自指（写三行，写完不许改）

1. **我在哪个位置看这件事**——身份、能接触到的信息、看不到的什么。若对象是机器生成物，本问改写为「这份语料由谁、用什么配置生成」（坐标从**主体**换成**生成条件**）。
2. **这件事成了什么样，对我有利**——写实话。
3. **我现在有没有预设情绪**——兴奋／恐惧／愤怒，有就贴在最上面。

这三行不产出结论，产出的是**读结论时要配的度数**。

### 结构四问（形式；内容是三铁律）

| 问 | 问什么 | 判错的样子 |
|---|---|---|
| **资源** | 钱、人、注意力从哪来、到哪去 | 只看「有多少钱」，不看「谁的钱」 |
| **规则** | 谁能定规则、规则保护谁 | 把规则当环境，忘了它是人写的 |
| **执行** | 谁真正动手、他对谁负责 | 把「名义责任」当「实际执行」 |
| **缓冲** | 冲击来时，谁先被牺牲 | 漏了这一问 ⇒ 把「还撑得住」当成「没问题」 |

**缓冲一问最容易被漏、也最值钱。** 判据：长尺度预言最大的风险敞口，就是答不上「缓冲」——1929 与 2020 的分水岭正在这一问（金本位不能印，无锚法币可以无限印）。

三条铁律是政治经济类现象的**内容**（答案总落在这三处）：**税基决定生死 ／ 货币主权是地基 ／ 代理层必然异化。** 同构必须落在**柱子的位置**上，不是落在剧情上（#10）。六域各自的「三根柱子」见 `references/存在论与现象学.md`。

### 先判对象类型，再判用哪把尺

**两条前置判据**

- **动作清单**（政治域）：先列**可观察的动作**（谁做了什么、谁没做什么、哪天说了什么），**再**谈评价。**不认动机陈述。**
- **压缩比**（判加工产物）：原文 ÷ 产物。**>20× = 判决书**（只留结论、丢弃辩驳过程，一眼可疑）；**<5× = 改写**（读起来完整，**最难起疑，也最危险**）。

**对象六类 → 该走哪条通道**（详见 `references/认识论_四通道.md`）

| 类型 | 特征 | 该走哪条通道 |
|---|---|---|
| **事件** | 有日期、有结果 | ① 命中 |
| **趋势** | 有方向、无终点 | ① 打点 + ② |
| **结构** | 慢变、无主体、无日期 | ③ 自洽 + 尺度 |
| **学说** | 有作者、要判自洽 | ② 文献 + ③ 自洽 |
| **技术** | 物质层有先例／本体层无先例 | ① 命中（弱）+ 边界 |
| **生成物** | 机器生成、**无利益位置**、可无限重生成、无原发日期 | **只能走 ③ 自洽** |

**类型判错，后面四步全错（#21）。**

## 四条检验通道（分开报，不合并总分）

| 通道 | 判据 | 典型体裁 |
|---|---|---|
| **① 命中** | 有**本文自己的未来时点**（时点四问） | 新闻、财经、时政、快讯 |
| **② 文献** | 查出处——他说的是不是来源里的话 | 学术论文、哲学笔记 |
| **③ 自洽** | 查论证——定义链是否自洽、有无偷换 | 佛学、心性、思想体系、史论 |
| **④ 信** | **文本自带禁止检验的条款** | 经文、开示 |

> **判错通道 = 判出假结论。** 用「命中」的尺去读哲学笔记，会得出「他什么都没说」；用「文献」的尺去读财经评论，会得出「他引注不规范」。**两者都不是结论，是拿错了尺。**

**实测反相关**：文献语密度与承诺密度几乎不共存。⇒ **一条文本通常只走一条通道；找到它走哪条，比评论它对不对更前置。**

- **① 时点四问**：**1 是未来吗**（时点须在成文之后；「基准年当年」须月日未到或句中有未来词；「五千年的文明史」这类年代跨度不计）· **2 是本文的吗**（引号／反引号内、以及 `据…报道`／`公告称`／《书名》指出 这类无引号**引述框架**内的，都算他人承诺）· **3 有「现在」吗**（相对时点如「明年／未来十年」须有绝对年份做当下锚定，否则只是**叙事时间**）· **4 够两处吗**（孤立的 1 处不算断言，行政／程序性日期最容易冒充）。
  产出是**四分词**：未来时点 ｜ 引述内未来时点 ｜ 本文时间线 ｜ 历史引用。判「可结算」＝ **≥2 处 且 ≥0.5/千字**；1 处记「弱·孤立」，≥2 处但稀疏记「弱·稀疏」，全是引述记「弱·只见引述」。
- **② 五查，顺序不可换**：**有**（出处存在吗，先找原始出处不用转引）→ **版**（锁定译本与版次）→ **字**（逐字比，先做空白归一化）→ **境**（引文边界切在哪，是否切在「但是／因此／然而」这类转折处）→ **界**（原文能支持到哪，作者推到哪；分清引用与发挥）。
- **③ 第 0 查 · 先查文体**：先判这份文本是**文言体／白话体／混合体**，再选表（文言表用 `者，謂／何以故／是故`，白话表用 `因为／所以／就是`）。**两套表都查不到 ⇒ 记「无标记」，不得据此判「不自洽」。** 随后四查：**定义**（同一个词各篇指的是同一个东西吗）／**归因层**（同一现象各篇归到哪一层）／**自指**（这个诊断能套在它自己身上吗）／**冲突**（同题并列的篇目之间有无直接打架）。
- **④ 的标志不是「不可检验」，是文本明说「不许检验」。** 强度分级：**劝信级** ＜ **定罪级**。
- **跨学说比较 · 三轴包含**：说「A 包含 B」之前，**先说是哪一轴**——**轴 1 尺度**（B 是 A 在某参数极限下的近似，**必须能算出修正项**）／**轴 2 论域**（B 是 A 在更强前提下的特例）／**轴 3 表示**（A 提供语言，不产生经验预测）。**只有轴 1 是真包含。**
  判不了包含 ⇒ 降级为「只是有交集」，用四条相交轴：归因层不同／尺度不同／**规范 vs 描述**／可否结算。

**元判据：理论成熟度 = 它自己声明的失效边界的明确度。** 有效场论、鲁棒控制、CAP、无套利之所以强，不是因为管得多，是因为把「不管的地方」写成了公式。反过来：**全称野心与可结算性负相关。**

## 定卡：没卡不算分析

深挖结束**必须**落成一张判断卡，否则这次分析不成立。**没写反证条件的，不算分析，只算感想；没写应验窗口的，也不算分析。**

判断卡最低要求（模板见 `references/方法论_判断卡与错因.md`）：

1. **有窗口**——写出「到某年某月，看某指标」；
2. **有分支**——A／B／C 三种走向，各带条件与应对；
3. **有反证条件**——写出「出现什么，我就认错」；
4. **有原发日期**——以**写作时点**为准，不以入库时点为准；
5. **两轴分记**——结构轴与叙事轴分开写，**禁止加权**。

窗口不是猜一个方向，是**先穷尽分支、再给每个分支写应对**。**写不出分支，是分类不完备，不是窗口不会写。**
窗口必须与断言**自己声明的级别**绑定回测（周线断言用 60/120 日，日线用 20/60 日，分钟级不用日线测）。**同一个语料换一个窗口，结论相反——换窗口得到的结论不作数。**

**双轴定位**（结构轴 × 叙事轴）：① **真事件**（两轴同步位移）／② **闷声的变动**（结构动了、说法没动——最危险，也最无人问津）／③ **纯舆论事件**（热闹，无实质）／④ 噪音。**只过一轴时必须说清是哪一轴。**

## 复盘：错因分类学（五选一）

事后只问一句「错在哪一层」：

1. **事实层**——事实搞错了 → 回去补第 1 步；
2. **结构层**——四问答错或漏了「缓冲」 → 补第 2 步；
3. **尺度层**——用错尺、跨尺度推论 → 补尺度表；
4. **立场层**——被叙事带走，或自己的预设污染了判断 → 回去看第 0 步写下的话；
5. **模型层**——问题本身不适用本体系（黑天鹅、纯随机、非结构性问题） → 记入「方法边界」，**不算失败**。

## 判读纪律（硬条目，逐字）

- **没有中立视角这回事。**
- **判错通道 = 判出假结论。**
- **① 的误判是双向的。** 判宽 ⇒ 把模板与流水账的占位日期当成预言；判严 ⇒ 把真判断卡误杀。**两个方向都是假结论，且都长得像结论。**
- **版本未锁定 ⇒ 后四查全部作废**，不得判「引错」。**先锁字形，正如先锁版本**——拿简体关键词检索繁體底本会得到全数假阴性，而**假阴性与「原文确实没有」长得一模一样**。
- **通道 ③ 的第一步不是找一致，是先让冲突显形。** 上来就求会通，会把冲突藏进措辞里。
- **结果是位置，动机是另一个问题。** 「谁受益，立场就在谁那边」推得出的是**客观位置**，不是主观意图——把位置写成意图，正是 #6。
- **规范 vs 描述永远不能互证；不能拿 A 档的成绩给 C 档背书。**
- 说「A 包含 B」时，**读者默认你在说轴 1**——所以必须写明是哪一轴。
- **不报总分。** 一次分析只报四格／两轴，**禁止加权**（#9）。
- 报比率必须给**三件套：语料 ＋ 单位 ＋ 数值**，且**不得跨语料引用**（#45）。
- **报数前先问「我漏掉了谁」。** 凡自动跳过的机制（语言、体裁、字数），都必须把**跳过的那一堆单独报出来**——**沉默的排除与沉默的通过，输出长得一样**（#37）。
- **判教是用来知道对方盲点在哪，不是用来给人评级。** 一变成评级，就是「判人者亦在判中」。
- **尺子不是手电筒，照别人的；尺子是镜子，照自己的。**
- **本体系不得被当成一条路。** 把「见路不走」当成一条路去走，就不叫见路不走——**方法一旦被当成可复制的一条路，它就死了。**
