# 可视化规范 · 看板是给「一眼看懂」的

**一句话**：看板回答**「这次是怎么想出来的、结论是什么」**，不回答「数据是多少」。

数据在报告里。看板**放全量明细就是失败**——没人会滚完一屏数字。

---

## 一、固定的八节骨架

顺序固定，缺哪节就**说明为什么缺**，不要用别的节凑数。

| 节 | 回答 | 形式 | 一眼要看出来 |
|---|---|---|---|
| **题头 + 结论** | 结论是什么 | 大字断言 + 4 个 KPI（置信度／窗口／双轴／行动） | 不滚屏就知道结论 |
| **A 分析路径** | 怎么想出来的 | **思维链**：纵向站点，每站「问什么 / 得到 / 砍掉」 | 方法不是黑箱；每步砍掉了什么 |
| **B 来源面** | 材料从哪来 | **两半对置条**（可达 / 缺席，缺席打斜纹）+ 在场／缺席行 | **桌子另一半是不是空的** |
| **C 四把尺子** | 敢不敢被打脸 | 4 个**环形图**（中心是数）+ 档位徽章 + 一句人话 | 哪条通道通、哪条不通 |
| **D 结构四问** | 结构长什么样 | 2×2 四格；**答不上的打斜纹 + 红字「答不上」** | 判定边界在哪 |
| **E 双轴定位** | 结构动了还是说法动了 | 2×2，**高亮一格** | 本次位置＝那一格 |
| **F 六域路由** | 谁有资格判 | 6 格：在场实心／拒答斜纹 | 拒答也是结论 |
| **G 反证条件** | 什么情况下我认错 | 3 条（可多不可少） | 判断可被推翻 |
| **H 边界** | 还缺什么 | ≤3 条 | 不吹 |

## 二、硬禁忌（做了就是失败）

1. **不放逐份明细表**——那是读数文件的事。
2. **不堆数字**——页面上的数只放「一眼要用的那几个」（结论 KPI 与四分词），不放全量。
3. **不放术语表、不放方法论讲解**——方法用**路径图**表达，不用文字讲。
4. **单节不超过一屏半**；全页超过 5～6 屏就说明该删了。
5. **不用饼图**（超过 3 块就读不出来）；用环形图／对置条／格。
6. **不新增判据**——看板只画**已经判出来的**。
7. **不放长段落**——每个格子一句话；长内容回报告。
8. **缺席必须可见**——只画在场，等于把偏置藏起来。

## 三、可读性自查（出图之后做，不是写完就算）

- 无头浏览器整页截图，按内容底边裁剪，**分 3～5 段目视**一遍。
- 逐项看：有没有**横向溢出**？窄列有没有被折成两行？有没有字面 `**` 或未渲染的标记？
  数字有没有被**粘成一个大数**（例：记录 6 ＋ 历史 2 拼成 `62`）？
- 题头层级：**题目最大**，副题小字灰；不要把一句长副题放大成标题。

## 四、数据契约（`{题名}_报告数据.json`）

字段全为中文键；**缺哪节就省略哪个键**，生成器会自动跳过。

```jsonc
{
  "题目": "台海局势",
  "副题": "材料来自联网抓取；台湾方面、美方、国际通讯社逐条试过——403 或超时。",
  "日期": "2026-10-01",
  "结论": {
    "断言": "周期尺度、未来 3 年内：……",
    "置信度": "低—中", "窗口": "到 2029-10-01",
    "双轴": "① 真事件 ＋ ② 闷声的变动", "行动": "观察"
  },
  "思维链": [ {"n":"00","站":"自指","问":"…","得":"…","砍":"…"} ],
  "来源面": {
    "说明": "…", "在场名": "大陆侧 · 全部简体", "缺席名": "台湾方面 · 美方 · 国际通讯社",
    "在场": [ {"名":"国台办 · 中央台办","数":11,"注":"…"} ],
    "缺席": [ {"名":"台湾方面","注":"站点不可达"} ]
  },
  "四通道": [ {"号":"①","名":"命中","档":"可结算 0 ｜ 弱 11 ｜ 不可执行 15",
              "级":"no","值":0.0,"数":"0","话":"一句人话",
              "四分":[{"k":"本文未来时点","v":21}]} ],
  "结构四问": [ {"问":"资源","答":"…","缺":"…"} ],
  "双轴": { "位置":"2", "格":[{"k":"1","t":"① 真事件","s":"…"}, {"k":"2","t":"② 闷声的变动","s":"…"}] },
  "六域": [ {"域":"政治域","态":"在场","注":"…"}, {"域":"金融域","态":"拒答","注":"…"} ],
  "反证": [ "交流措施出现「回撤」" ],
  "边界": [ "台湾方面与美方的一手文本仍缺" ],
  "边界注": "本页只画已经判出来的结论，不新增判据。",
  "脚注": "材料：… · 读数：sitongdao（V37）· 判据：social-analysis"
}
```

取值约定：

- `四通道[].级`：`ok`（绿）／`mid`（黄）／`no`（灰）——**档位低不等于结论差**，别为了好看调高。
- `四通道[].值`：0～1，画环用。**① 用「可结算 ÷ 总份数」**（0.0 是常态，环是空的——空环就是结论）。
- `六域[].态`：`在场`（实心）／`拒答`（斜纹）／其他（灰）。
- `结构四问[].答` 留空 ⇒ 自动渲染成斜纹格 + 红字「答不上」。

## 五、跑

```
python "<social-analysis>/scripts/build_report_html.py" "{题名}_报告数据.json" -o "{题名}_可视化看板.html"
```

纯标准库；输出**单文件 HTML**，无外部依赖、无联网、无 JS。

## 六、第二条产线：archify 关系图（结构图 / 路径图）

**分工**：`build_report_html.py` 出**八节骨架看板**（结论面）；archify 出**关系图与路径图**（结构面、流程面）。两者都要，不互替——看板回答「结论是什么」，archify 回答「它们怎么连、这一步怎么走」。

### 什么时候用哪一类

| 要表达 | `diagram_type` |
|---|---|
| 谁和谁连、哪条线在跑、哪一块缺席 | `architecture` |
| 分析的每一步怎么走、哪里分叉、哪里退回 | `workflow` |
| 谁先谁后、请求与回应往返 | `sequence` |
| 数据从哪流到哪、在哪被改写 | `dataflow` |
| 阶段／状态推进（含失败与回滚） | `lifecycle` |

### 怎么跑

```
node "<archify>/bin/archify.mjs" finalize <type> <candidate.json> <out.html> --quality showcase --json
```

四道闸 `validate / deliver / check / browser-check` **全 `pass` 且 `ok:true`** 才算过。**别只看「文件生成出来了」就当成功。**

### 踩过的坑（照抄，别重踩）

1. **用 `schema_version: 2`**。v1（fixed-v1）列距死板，节点一宽就报 `workflow/column-capacity` 互压；v2 会自己排。参照物：`examples/agent-tool-call.workflow.json`。
2. **不要手写 `meta.viewBox`**。写了它**不算** intrinsic fit，反而同时踩两条互斥硬约束：宽高比 <1.55 报 `composition/viewport-height`；宽 >976 报 `composition/desktop-readability`（文字会被缩到 6px 以下）。**让渲染器自己定画布**，再用节点宽度把画布撑到宽高比 ≥1.55。
   - 实测：6 列 × 6 泳道 → 720×900（比例 0.80）必挂；**砍到 4 泳道** + 节点 `width: 150` → 1058×660（比例 1.60）过。
   - **泳道数就是门槛**：6 泳道最低 838 高、5 泳道 714、4 泳道约 590。高要 ≤ 约 630 才配得上 ≤976 的宽。
3. **`tag` 字段不渲染**。节点上只画 `label` 与 `sublabel`。要表达「第三件事」就并进 `sublabel`，用 `｜` 分隔（例：`两条线并行｜缓冲答不上`）。
4. **子标签超宽**报 `layout/constraint`——写短，别硬撑。
5. **重跑前删掉 `<out>.browser-check.json`**，否则 `viewer/evidence-path-conflict`（旧凭据不属于本次 artifact）。删掉即过。
6. **边标签压到节点** → 给那条边加 `labelDy`（如 14）或 `labelAt`。
7. 泳道会自动编号 `01 /`、`02 /`…，节点标签**不要再用同样的数字打头**（改用 `S0…S6`），否则读者串号。

8. **结构图只画关系 = 读者收获不到结论。** 图里必须有一条**推论带**：`推论① → 推论② → 推论③ → 断言`，用自己的边界框标「由上面的结构推出」；**卡片第一张必须是结论卡**（断言 ＋ 置信度 ＋ 窗口 ＋ 行动）。只看关系图的人，也要一眼拿到结论。
9. **看板截图要看真实高度。** 按固定窗口截图会**截短**（实测：窗口 3000px，页面实际 4,490px）。必须**先探测内容底边再裁剪**，再分片目视。
10. **Edge 无头截图会复用后台进程 → 截到旧文件。** 加 `--user-data-dir=<临时目录>`，并**先删旧 png**再截。
