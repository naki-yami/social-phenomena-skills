# 方法论：判断卡与错因

## 三种站位（分析者只有三种姿势）

| 姿势 | 动作 | 在分析里长什么样 |
|---|---|---|
| **第一种 · 跪着看** | 把对象当要合的神 | 跪趋势（「跟不上就被淘汰」）、跪数据、跪权威 |
| **第二种 · 站着看** | 把自己当能算准的观测者 | 迷信模型、迷信自律、以为看穿了就是掌控了 |
| **第三种 · 动手做** | 不跪对象，也不跪自己，**问「手头这件具体的事能做什么」** | 看清处境，然后**动一次手** |

> **它不让你当观众（无论跪着看还是站着看都是观众），它让你当选手。** 趋势是场上的一部分，不是裁判。

**分析的目的不是看准，是能出手。一份让你更不敢动的分析，无论多深刻，都是失败的。**

## 尺度表（先写尺度，再写断言）

| 尺度 | 跨度 | 判断对象 | 证伪时窗 |
|---|---|---|---|
| **事件** | 小时–周 | 一次会晤、一次发言、一次暴跌、一场风波 | 1–4 周 |
| **周期** | 季度–十年 | 政策转向、产业迁移、资本周期、化债 | 1–5 年 |
| **历史** | 十年–百年 | 王朝、制度、文明、货币体系 | 一代人以上 |

**铁律：用历史尺的判断去做事件尺的预测，是这套方法第一大翻车点。** 每次分析必须显式写出尺度；**跨尺度推论必须标「跨尺度，仅作背景」。**

**体裁维**：下注密度主要由**体裁**决定（经文 ＜ 学术哲学 ＜ 思想体系 ＜ 史论 ＜ 自媒体财经 ＜ 机构媒体 ＜ 快讯）。⇒ **说「这份材料下注稀薄」之前，先问「它是什么体裁」**——两者都不说明材料好坏，只说明它走哪条通道。

## 判断卡模板

```
【判断卡 · 编号 YYYY-MM-DD-NN】
日期：
事件一句话（去形容词）：
尺度：事件 / 周期 / 历史

结构轴：四问里动的是哪一问？动了什么？
叙事轴：谁在讲哪个版本？术语有无漂移？
代价流向：谁获益 / 谁承担 / 为什么落在这一层
双轴定位：① 真事件 / ② 闷声变动 / ③ 纯舆论 / ④ 噪音

一句话断言：
  预期在____尺度上、____时间内，出现____。
应验窗口：
  把未来穷尽为 ____ 个分支（不是猜一个方向）：
    分支 A：____ → 应对 ____
    分支 B：____ → 应对 ____
  到____（具体日期或区间）仍未见任一分支成立，即为未应验，或分类失效。
反证条件：
  如果出现____，则本判断为错。
置信度：高 / 中 / 低（低置信度允许保留，但必须标注）
行动：无 / 观察 / 具体动作
```

**五条最低要求**：有窗口 ／ 有分支 ／ 有反证条件 ／ 有原发日期（以**写作时点**为准）／ 两轴分记且**禁止加权**。

### 纪律

- **反证条件写不出来的，直接删掉这条判断。** 能说出自己怎样会错，才算真的看见了结构。
- **给不出应验窗口的断言，降级为「感想」，不进判断卡。** 理由很硬：**话术之所以能永远正确，全靠没有窗口**——没有窗口就永不逾期，也就永不可判。**给窗口，是把话交出去的过程。**
- **窗口不是猜一个方向，是先穷尽分支、再给每个分支写应对。** **写不出分支，就是分类不完备，不是窗口不会写。** 只给一个方向的「预测」，必然要么永远正确、要么马上错，两边都学不到东西。
- **尺度绑定**：断言必须与**它自己声明的级别**绑定回测（周线断言用 60/120 日，日线用 20/60 日，分钟级不用日线测）。**同一个语料换一个窗口，结论相反——换窗口得到的结论不作数。**
- **元数据纪律**：拿到语料**先问一句「它什么时候写的」**。发布日期缺失的原始资料，**永久失去时滞可测性**，且事后不可补。**入库即录原发日期，是这套方法里唯一能提前做、事后做不了的事。**
- **前瞻性纪律**：判一句话是不是「前瞻」，**必须以它自己的写作时点为准**——「句中提到的年 > 写作年」才算前瞻。把年份写死成绝对区间，一放到库外就露馅。
- **归属纪律**：每条承诺性句都要问「**这是作者在说，还是作者在转述？**」——**转述不计入下注度**。这条**不能全交给机器**（机器假阳性很高）。稳态判据是**作者身份可追溯**；**佚名语料的「自有判断」数字一律降级为估计值。**
- **压缩比纪律**（判加工产物）：原文 ÷ 产物 >20× 是判决书，<5× 是改写——**改写最难起疑，也最危险。**

## 错因分类学（复盘五选一）

事后只问一句「错在哪一层」：

1. **事实层**——事实搞错了 → 回去补第 1 步；
2. **结构层**——四问答错或漏了「缓冲」 → 补第 2 步；
3. **尺度层**——用错尺、跨尺度推论 → 补尺度表；
4. **立场层**——被叙事带走，或自己的预设污染了判断 → 回去看第 0 步写下的话；
5. **模型层**——问题本身不适用本体系（黑天鹅、纯随机、非结构性问题） → 记入「方法边界」，**不算失败**。
