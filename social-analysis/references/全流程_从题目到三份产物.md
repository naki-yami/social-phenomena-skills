# 全流程 · 从一句题目到三份产物

**触发**：用户说「分析 X」「分析一下 X」「看看 X 怎么回事」——即默认走本流程，不需要再问一遍。

**产出固定为三份**（2026-10-01 定版）：

| 产物 | 全称 | 给谁看 | 里面放什么 |
|---|---|---|---|
| **报告文本** | `{题名}分析_{日期}.md` | 要查数、要复现的人 | **全量**：逐份读数、全部数字、判据、推理链、边界 |
| **发表稿** | `{题名}_发表稿_{文章标题}.md` | 普通读者 | **文章体**：同一个结论，换成能直接发表的语言 |
| **结构图** | `{题名}_结构图_archify.html` | 要一眼看懂的人 | **结构与推论**：谁和谁连、哪一块缺席、这张结构推出什么 |

**不默认交付（可作中间产物，做完移入 `outputs\_未采用\`，留档不删）**：`{题名}_可视化看板.html`、`{题名}_分析路径_archify.html`。

**分工是硬规矩**：数字与明细**只住报告**；发表稿只带**能在正文里站得住的那几个数**；结构图**不放明细**。
看板一旦变成数据仓库，就没人看了——这也是它被移出默认交付的原因。

---

## 六步（次序不可换）

### 第 1 步 · 要联网

材料要自己去拿。**先确认本轮有网络权限**——本机沙箱默认断网，需要按轮申请。
没网就别假装分析：明说「拿不到材料」，只出结构层，并把它标成**未验证**。

### 第 2 步 · 先列「谁可能有话要说」，再去抓

**不要**先搜再想。先写下这张表（哪怕最后只拿到一半）：

1. **当事各方**（每一方各自的官方／一手发布）；
2. **第三方**（监管、通讯社、研究机构、行业）；
3. **反向材料**（说自己错的、唱反调的）；
4. **底本**（法条、文书、白皮书、档案）。

抓完逐条回填：**拿到了几份？谁一份都没拿到？**——**缺席的那一行照样写在产物里**（见下「来源面」）。

### 第 3 步 · 取料

- **可达性要实测，不要推测。** 每站逐条试，记下 `403 / 超时 / 可搜但无相关`。
- 落盘目录：`{题名}_素材\`；抓取日志与**被排除**的索引页放 `{题名}_素材_排除\`。
- 每份语料带 frontmatter：`title / 分类 / 来源 / 原发日期 / 抓取时间 / 语种`。
  文书类另加 **`文书日期`**——**网页发布日期 ≠ 文书原发日期**（白皮书页面 2011、文书 2000）。
  没有原发日期 ⇒ ① 的时点判据**全不可判**，先补 `--base-year`，或放弃 ① 只报 ②③④。
- **排除必须留痕，不静默删除**；日志要逐份报。**沉默的排除与沉默的通过，输出长得一样。**
- 抓取日志**不是语料**——别把 `_抓取日志.md` 留在语料目录里被当成一份。

### 第 3.5 步 · 分流（**这一步会改事实，下游必须重数**）

抓到的不等于留下的。写报告**之前**做一次分流：索引页、导航页、检索页、归档页、无关页**移出去**，留正文。

**分流 = 一次搬运，搬运会改变事实。** 分流之后，**任何按「份数」写的表（来源面、各分类计数、看板数据、结构图节点）都必须重新数一遍**，不能沿用抓取时的快照。

> **实测教训（2026-10-01，AI 局势）**：报告第三节来源面表沿用了**分流前**的抓取快照，把已经移出的索引页算成了在场（美方官方记 2 实际 1、欧盟／英国／联合国记 2 实际 1、第三方研究记 5 实际 6、反向材料记 3 实际 4）。总数仍是 26，**只有分桶错了——所以它不会触发任何自动检查，只能靠逐份重数抓出来**。
> **对策**：分流后跑一次逐份重数，用**语料自己的 `分类` 字段**汇总，与所有产物里的分桶对齐；对不上就改，并**在正文以「订正」块留痕，不静默改数**。

### 第 4 步 · 跑读数

```
python "<sitongdao>/scripts/四通道批处理.py" "{题名}_素材" --out "{题名}_四通道读数.md" --json "{题名}_四通道读数.json"
```

四条通道**分开报，不合并总分**。读法见 sitongdao。

### 第 5 步 · 分析（走 social-analysis 的次序）

第 0 步自指 → 判对象类型 → 结构四问 → 双轴 → 六域路由 → **判断卡**（窗口／分支／反证条件／置信度）。
判不了的部分**必须写出来**，不许用「分析写得顺」来补。

### 第 6 步 · 出三份产物

1. **报告文本** `{题名}分析_{日期}.md`。**先把「这份分析能说什么、不能说什么」写在最前面**——来源面偏置要**连着结论一起报**。
2. **发表稿** `{题名}_发表稿_{文章标题}.md`。规矩：
   - **不带方法论术语**：`自指／四通道／命中·文献·自洽·信／双轴／六域路由／判断卡／置信度档位／失效模式编号／来源面偏置` 这些词**一律不出现在正文里**。
   - **该有的一个不少**：结论、**把握程度**（用平实的话，如「本文最不确定的部分」）、**三条反证**（写成「什么情况下这篇文章是错的」）、**取材缺口**（单列一节，逐条写清缺了谁、为什么缺、哪个缺口是「没去试」）。
   - **数字必须与报告一致**——写之前先做第 3.5 步的重数。
   - 骨架：导语（一个具体的事实落差）→ 分节叙事 → 该盯什么 → 我错的条件 → 关于材料 → 结语。
   - 署名与体裁：**文章体**，不是内部备忘；不写「本报告」「本轮」，写「本文」「这篇文章」。
3. **结构图** `{题名}_结构图_archify.html`：

```
node "<archify>/bin/archify.mjs" finalize architecture <candidate.json> <out.html> --quality showcase --json
```

   四道闸全 `pass` 且 `ok:true` 才算过。**结构图必须自带结论**：
   - 一条**推论带**：`推论① → 推论② → 推论③ → 断言`，用自己的边界框标「由上面这张结构推出」；
   - **卡片第一张是结论卡**（断言 ＋ 把握程度 ＋ 窗口 ＋ 行动），末位两张是**判不了什么**与**反证条件**。
   只画「谁和谁连」而不画「推出什么」＝读者收获不到信息，返工。
   细则见 `references/可视化规范.md` 第六节。

## 交付（容易被忽略，但用户只看这一步）

**产物生成完不算交付。** 交付＝让用户**当场点得开**：

1. **三份产物全部用 `open_in_codex` 打开**——HTML 会以 **Web preview 卡片（带 Open in）**出现在对话里，md 以文件卡片出现。
   **不要**只给一个路径字符串，**不要**把 HTML 源码或正文贴进对话。
2. **对话里只说三句**：结论是什么、把握有多大、还缺什么。**正文一律不贴**——正文在文件里。
3. **图也不贴**（除非用户明确要）。
4. 只有用户明确说「贴出来」「全文」时，才在对话里贴正文。
5. **交付前最后一次重数**：语料份数、各分类计数、结构图节点计数，三处必须一致。

一句话：**对话给入口，文件给内容。**

## 来源面这一条（最容易漏，也最该写）

抓完必须回答一句：**这张桌子的另一半是不是空的？**

- 只拿到一方 ⇒ 结论只能写成「**这一方的叙事说了什么**」，**不能**写成「**这件事整体如何**」。
- 这是 `#32 来源面偏置`。**它不是免责声明，是一条读数**：它决定了置信度上限。
- 图里**缺席必须看得见**（斜纹／独立分组），不能只报在场。
- **「没抓到」和「没去试」要分开写。** 前者是可达性问题，后者是**取样设计**的缺口——用闸门掩盖取样缺口，等于自欺。

## 记账

每轮收尾写一条工作记录：抓了哪些站、哪些不可达、**修正了什么**（例：27→26、分桶重数）、
逼出了哪条失效模式、哪条「记账不装」。**不装的记录和装的记录一样留在账上。**

## 目录约定

```
outputs\
  {题名}_素材\                        # 语料，逐份带 frontmatter
  {题名}_素材_排除\_抓取日志.md        # 抓取与排除留痕
  {题名}_四通道读数.md / .json          # 机器读数
  {题名}分析_{日期}.md                 # ① 报告文本（全量，方法论体）
  {题名}_发表稿_{文章标题}.md           # ② 发表稿（文章体）
  {题名}_结构图_archify.html            # ③ 结构图（含推论带 ＋ 结论卡）
  {题名}_报告数据.json                 # 中间产物（看板输入，留档）
  _未采用\                            # 撤下的看板／路径图（留档，不删）
  .archify\<type>-<题目>-<名>\          # archify 候选与四道闸凭据（保留，别删）
  工作记录_{日期}_{题名}.md             # 本轮账目
```
