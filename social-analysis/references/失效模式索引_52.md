# 失效模式索引（52 条）

用法：**分析前扫一眼，分析后再扫一眼**。命名它，是为了在别人（或自己）说出那句话时立刻认出来。完整条目（含每次实测的语料与读数）在体系层与操作层原文里，本表不复制读数。

## 通例（#1–#20）

| # | 名称 | 症状 |
|---|---|---|
| 01 | 万能钥匙谬误 | 一把尺解释一切，什么都能套 |
| 02 | 马后炮 | 只解释已发生的事，从不预测 |
| 03 | 遮羞布反转 | 分析者自己造新遮羞布：「这是结构问题」成了免责声明 |
| 04 | 判教傲慢 | 用判教贬低人，而不是定位盲点 |
| 05 | 尺度混用 | 用百年尺解释一周的事 |
| 06 | 结构推断冒充意图断言 | 把「这样做对 X 有利」写成「X 想这么做」 |
| 07 | 术语漂移感染 | 跟着对方的词走，用对方造的框架说话 |
| 08 | 自指缺失 | 不写自己的预设和利益位置 |
| 09 | 总分癖 | 加权合成一个「重要性评分」 |
| 10 | 无脑同构 | 表面相似当结构同构 |
| 11 | 转述过滤 | 二手材料把可证伪的部分删掉了，剩下的读起来天衣无缝，却什么也检验不了 |
| 12 | 无对照的指标 | 用一个漂亮指标下结论，却没跑对照组——指标可能只是在测量显而易见的东西 |
| 13 | 缺席即不可复核 | 判定所依据的原文从未入库，判定无法被任何证据推翻或修正 |
| 14 | 借壳标注 | 自撰文字因大量使用某人的术语，被标为该人「原文」，从此免于检验 |
| 15 | 空白领域最易被假托 | 某人的某领域是空白，这个空白反而成了假托的温床 |
| 16 | 追认型伪装成证据 | 对已发生走势的复盘，被当成「判断准确」的证据累积 |
| 17 | 粒度盲区 | 语料已在库、可通读，但关键断言落在拿不到的数据粒度上（分钟级／盘口级／非公开） |
| 18 | 复述冒充分析 | 密集出现他人计划的准确数字，读起来像深度分析，但没有一条是作者自己的判断 |
| 19 | 仪器被复述污染 | 指标把「引述」算成「判断」，量到的「下注度」实为「转述密度」 |
| 20 | 版本误判 | 拿 A 译本去核对引用 B 译本的作者，把版本差异记成篡改 |

## 体系层新增（#21–#52）

| # | 名称 | 症状 |
|---|---|---|
| 21 | 类型误判 | 尺没错，错在没先判类型（事件／趋势／结构／学说／技术／生成物） |
| 22 | 跨体系核字 | 拿 A 体系的定义去核 B 体系的用法，把判教差异判成自相矛盾 |
| 23 | 回灌虚增 | 自动化流程把上下文回灌与程序日志计入内容，再按字数分配权重 |
| 24 | 给无立场对象反推立场 | 把模型输出读成「它想说什么」（拟人化），或读成权威 |
| 25 | 生成物越界 | 生成物不是一个领域，是一层跨域污染；且不可自证 |
| 26 | 框架冒充文本 | 拿注疏／科判的术语去原文里查定义，结果全部查空 |
| 27 | 检索失真 | 把检索命中数当证据：子串假阳性 + 通名假阴性（须分字形、分专名／通名、防邻字吞并） |
| 28 | 判据的文体偏置 | 用文言词表量白话文本，得到全数假阴性 |
| 29 | 元数据冒充内容 | frontmatter／页眉／目录行被当正文统计 |
| 30 | 叙事时间冒充本文时点 | 小说、史书里的「下个月／明年」是叙事时间，不是作者的预言 |
| 31 | 聚合体与成员重复计数 | 日报转单篇，同一件事被计两次 |
| 32 | 来源面偏置 | 只看一边的源；两半来源完全不同时只报一个总数 |
| 33 | 同形异域 | 同一个字串落在两个语用域里，判据却不分流 |
| 34 | 同形异能 | 认了「形」没认「用」——同一个字串可以做几种言语行为，把「非禁令」的用法一并算进「禁令」 |
| 35 | 基准年固化 | 拿「现在」当所有文本的基准年 ⇒ 历史文本里的未来判断被整片读成过去 |
| 36 | 标定迁移谬误 | 把 A 语料上标定出的精确率当成判据的固有属性搬到 B 语料——崩得静默 |
| 37 | 语言面静默跳过 | 纯英文语料因「汉字数不足」被整份丢弃 ⇒ 与「读了、确实没有」同形 |
| 38 | 版面日期冒充本文时点 | 刊头的发刊日被计成正文的将来时点 |
| 39 | 归档索引区冒充本文时点 | 往期目录里的未来年，被认成本期正文的时点 |
| 40 | 回顾式相对时点 | 时长型（本季度／N 个月内／窗口期）自身不含方向，须与前瞻词同现 |
| 41 | 取消式计划 | 「已取消的计划」不构成可结算断言：文本层照计、可结算层剔除 |
| 42 | 尾栏导航区冒充本文时点 | 文末「前一日／后一日」行及其后标题行被当正文 |
| 43 | 已完成式时长 | 时长型后 12 字内见「了」⇒ 回顾 |
| 44 | 跨域重复计数 | 一处证据被两域各记一次，再相加 |
| 45 | 虚增率的单位缺失 | 报出一个百分比而不说单位、不说语料 ⇒ 被当成常数／特征值 |
| 46 | 会计期间名冒充未来时点 | 「Fiscal 2027」是已开始的会计期间名，不是未来年 |
| 47 | 非正文要素区冒充本文时点 | 尾注区／表头行与正文用同一种日期写法 |
| 48 | 行内引注年份冒充时点与锚定 | 论辩稿里的「命中」绝大多数是参考文献年 ⇒ 照 ① 口径报数近似全数假阳性 |
| 49 | 伪将来时 | 叙事文本的「明年」默认不是本文的未来；假锚来自书前序跋／版权页 |
| 50 | 编号冒充日期 | 订单号／编号被读成日期 |
| 51 | 取消闸门的语种与词面缺口 | 闸门只覆盖一种形态（中文·新闻体·取消动词同分句），**不是能处理这一类文本** |
| 52 | 第三语种的三条落法 | 语言路由只在中英上标定过；西里尔→被静默跳过，拉丁非英语→用英文表量，汉字圈非中文→用中文表量 |
