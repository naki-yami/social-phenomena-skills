# 四通道（工具）

把 `social-analysis` 认识论第二步的**四条检验通道**做成可批量执行的脚本。**自包含：只用 Python 标准库，不联网、不装包。**

判据、纪律、失效模式在 `social-analysis` 里；本 skill 只讲**怎么跑、怎么读、什么时候不许跑**。工具的完整读法与全部已知边界写在同目录 README 里（见文末路径）。

## 跑

```
python "<skill>/scripts/四通道批处理.py" <路径...> [--kw 词1 词2 ...] [--out 报告.md] [--json 数据.json] [--base-year 2026]
```

- `<路径>` 可为文件或目录（目录递归，只收 `.md / .txt / .markdown`）
- `--kw` 关键词核字：跨字形双查 ＋ 邻字分级 ＋ 宿主串（长吞并词）
- `--terms 词表.txt` 专名／通名双查（每行 `通名|专名1,专名2`）
- `--base-year` 定 ① 的语料基准年；**与成文年相差 ≥3 年会在报告里打 ⚠「① 判定作废，须重跑」**
- `--json` 出机器可读分数；`--quiet` 只出结论

`scripts/简繁字典.tsv` 必须与脚本同目录（脚本按自己的路径找它）。

## 读（关键）

1. **四条通道分开报，不合并总分**——判错通道 = 判出假结论。
2. **先看字形，先看语言。** 字形落在「混合」或比例可疑的，核字前必须双查；`ja／ko／cyr／other` 会被**显式拒绝**（既不套中文表、也不落进英文表）。
3. **中文表与英文表是两套同功能判据，不是一套的翻译**——英文密度按每千词，**禁止与中文合并成分数**。
4. **① 读四分词**：未来时点 ｜ 引述内未来时点 ｜ 本文时间线 ｜ 历史引用。判「可结算」＝ **≥2 处 且 ≥0.5/千字**；1 处记「弱·孤立」。
5. **被跳过的文件必须逐份看**——报告会打印 `unit=<实测> < 50 lang=<语种>`。**沉默的排除与沉默的通过，输出长得一样。**
6. **报告里的「已知边界」是读数的一部分**：哪些闸门只覆盖一种形态（例：取消闸门只覆盖「中文·新闻体·同分句」）、哪些表在哪些语种上未标定，都写着——**报数时要连着边界一起报。**

## 什么时候不许跑，或跑了别信

- 语料**没有原发日期** ⇒ ① 的时点没有基准：先补 `--base-year`，或**放弃 ① 只报 ②③④**。
- 语料是**机器生成物** ⇒ 只能走 ③；① 无意义（#24 给无立场对象反推立场）。
- 语料是**第三语种（日／韩／西里尔）** ⇒ 会被显式拒绝；**不得**把中文表套在日文／韩文上（#52）。
- **英文侧的 ③（定义式／论辩式）未标定**——只报数，不判读。
- **文件级 ① 读数不能替代人工判读**：它是筛子，不是判决；① 的结论要按「时点四问」逐处回看。
- **换语料就要重标定**：在 A 语料上标定出的精确率**不得**搬到 B 语料（#36）。

## 三条闸门纪律（写闸门、报读数时都适用）

1. **版面识别按「谁生成的」判，不按「在文件哪个位置」判。**
2. **闸门的「紧」要加在动词的时相上，不要加在标点的距离上。**
3. **报数前先问「我漏掉了谁」。**

**装新闸门的门槛**：**0 真损失** ＋ **抽检精确率**（**等距抽样，不得按出现顺序取**）。达不到就不装，并把「记账不装」写下来——**不装的记录和装的记录一样留在账上。**
